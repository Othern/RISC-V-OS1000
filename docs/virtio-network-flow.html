VirtIO Network、Interrupt 與 ARP 流程

對應目前專案實作：VirtIO MMIO network device、RX/TX split virtqueue、PLIC IRQ 2、interrupt-driven completion、RX capture ring、shell 可變 payload，以及基礎 ARP request/reply 與 cache。

Kernel / Driver Virtqueue / Ethernet QEMU Device PLIC / Interrupt ARP

目前完成的網路層次

VirtIO-Net Driver

掃描 MMIO device、建立 queue、管理 RX/TX buffer，並處理 VirtIO interrupt status/ACK。

Ethernet Layer 2

建立與解析 destination MAC、source MAC、EtherType 與 payload。MAC 固定為 52:54:00:12:34:56。

ARP

本機 IPv4 為 10.0.2.15，支援 Request、Reply、8-entry cache 與 deferred reply。

PLIC Interrupt

VirtIO network 使用 PLIC IRQ 2。CPU claim 後執行 virtio_net_irq()，最後 complete。

QEMU Backend

NETDEV=user 提供虛擬網路；NETDEV=tap 可讓 host 直接觀察與注入 Ethernet frame。

Shell / Syscall

send <message> 發自訂 EtherType payload；arp <IPv4> 查詢 MAC；arp 顯示 cache。

Packet 在 Buffer 中的排列

virtio_net_hdr 10 bytes，目前 flags/GSO/checksum 欄位為 0。
Ethernet MAC Destination 6 bytes + Source 6 bytes。
EtherType 0x88b5 測試，0x0806 ARP。
Payload Shell message 或 28-byte ARP packet；Ethernet frame 不足 60 bytes 時補 0。
virtio_net_hdr 是 VirtIO transport metadata，不屬於線上的 Ethernet frame。RX 解析與 hex dump 都從 destination MAC 開始。

Kernel 初始化順序

點選步驟可逐段閱讀。Global interrupt 最後開啟，避免 queue 或 handler 尚未準備完成就進入 IRQ。

1Kernel→ 設定 trap 與 allocatorstvec = kernel_entry、sscratch = 0，接著初始化 page allocator。
2VirtIO Probe→ 掃描 VirtIO MMIO slots從 0x10001000 到 0x10008000，尋找 device ID 1 的 network device。
3VirtIO Status→ Reset、ACKNOWLEDGE、DRIVER設定 legacy MMIO page size，開始配置 split virtqueue。
4Queues→ 建立 RX queue 0 與 TX queue 1配置 descriptor table、available ring、used ring，以及 RX/TX packet buffers。
5RX Pool→ 預先交出 16 個 RX buffersdescriptor 設定 VIRTQ_DESC_F_WRITE，加入 available ring。
6Device→ 設定 DRIVER_OK 並 notify RX queueQEMU device 現在有可寫入的 RX buffer。
7ARP→ 初始化 ARP 狀態清空 8-entry cache 與 pending reply，本機 IPv4 設為 10.0.2.15。
8PLIC / CPU→ 啟用 IRQ 1/2 與 CPU external interruptPLIC priority/enable/threshold 完成後，設定 sie.SEIE 與 sstatus.SIE。

RX 與 Interrupt-Driven Completion

1Backend→ QEMU 收到 Ethernet frame來源可以是 user networking、TAP host 或 host 注入工具。
2Device→ 寫入 RX descriptor先寫 virtio_net_hdr，再寫 Ethernet frame，更新 RX used ring。
3PLIC→ 提出 VirtIO network IRQ 2CPU 以 supervisor external interrupt 進入 trap，claim 得到 IRQ ID 2。
4Driver→ ACK VirtIO interruptvirtio_net_irq() 讀 InterruptStatus，寫 InterruptACK。
5RX Drain→ Drain 整個 used ringvirtq_pop_used() 取得 descriptor ID 與長度，解析 EtherType。
6Dispatch→ Capture 與 EtherType dispatchframe 複製到 16-entry capture ring；0x0806 交給 arp_receive()。
7Recycle→ RX buffer 放回 available ring所有完成項目處理後才 notify RX queue，持續維持 buffer pool。
8PLIC→ Complete IRQ 2外層 handler 寫 PLIC claim/complete register，結束 in-service 狀態。
步驟 1 / 8
正常路徑不再反覆 polling used ring。virtio_net_poll() 仍保留為除錯 fallback，但 kernel boot 與 RX 測試依賴 IRQ 更新 completion。

Shell 可變 Payload 到 TX Completion

1Shell→ 輸入 send <message>例如 send Hello VirtIO，shell 計算實際字串長度，不包含結尾 NUL。
2Syscall→ SYS_SENDuser wrapper 將 payload pointer 與長度傳入 kernel。
3Ethernet→ 建立 broadcast 測試 framedst 為 broadcast、src 為本機 MAC、EtherType 為 0x88b5、payload 為 shell message。
4TX Queue→ 填 descriptor 0 並 kickdescriptor 不設 WRITE；frame 不足 60 bytes 時補 0。
5Wait→ 等待 net_tx_donewait_for_interrupt() 使用 completion flag 與 WFI，避免 busy loop。
6Device / IRQ→ Device 送出並更新 TX used ringIRQ 2 進入 virtio_net_drain_tx()，更新 counter 並設定 done。
7Shell→ syscall 回傳 payload bytesshell 顯示 send: N bytes。這代表 device 完成 TX descriptor。
步驟 1 / 7
TX 目前只有一個 buffer 與一個 outstanding request，因此 API 是同步的。若要支援高吞吐量或從多個 context 傳送，需要 descriptor free list、TX software queue 與 per-request completion。

ARP Request、Cache 與 Deferred Reply

Request

arp 10.0.2.2 送出 broadcast Ethernet frame，EtherType 0x0806，ARP operation 為 1。

Cache

收到合法 ARP Request 或 Reply 後，先學習 sender IPv4/MAC。cache 固定 8 格，滿時覆蓋第 0 格。

Reply

若 target IP 是 10.0.2.15，IRQ context 只保存 pending reply；arp_poll() 稍後送出 operation 2。

ARP Request 流程

1Shell→ 解析 dotted IPv4arp 10.0.2.2 轉成 32-bit IPv4，呼叫 SYS_ARP_REQUEST。
2ARP→ 建立 28-byte ARP Requestsender IP 10.0.2.15，target MAC 全 0，target IP 為查詢位址。
3Ethernet→ Broadcast 發送destination ff:ff:ff:ff:ff:ff，EtherType 0x0806。
4RX IRQ→ 收到 ARP Replyarp_receive() 驗證 Ethernet/IPv4 ARP 欄位並取得 sender mapping。
5Cache→ 更新 IPv4 → MACshell 再輸入 arp 可顯示學習結果。
