VirtIO Network 初始化與操作流程

這份 HTML 圖解對應本專案目前的 virtio-net skeleton：QEMU 掛上 MMIO network device，kernel 掃描 device id，初始化 RX/TX queue，預先提供 RX buffers，並用 TX queue 送出測試 Ethernet frame。

2. 初始化流程

Kernel
QEMU boot 後進入 kernel_main() 先初始化 allocator，再初始化 virtio block / network。
↓
virtio_find_device(VIRTIO_DEVICE_NET) 掃描 0x10001000 到 0x10008000 的 VirtIO MMIO slot。
↓
檢查 Magic / Version / Device ID network device id 應為 1。
↓
設定 device status reset → ACKNOWLEDGE → DRIVER → page size。
Virtqueue
建立 RX queue 0 device 用這條 queue 寫入收到的 Ethernet frame。
↓
建立 TX queue 1 driver 用這條 queue 交出要送出的 Ethernet frame。
↓
配置 RX buffer pool 每個 descriptor 都指向 virtio_net_hdr + Ethernet frame buffer。
↓
把 RX descriptors 放入 avail ring 設定 VIRTQ_DESC_F_WRITE，表示 device 可以寫入。
VirtIO-Net Device
收到 DRIVER_OK device 開始接受 queue request。
↓
RX queue notify device 得知 driver 已提供可寫入的 RX buffers。
↓
等待封包或 TX request QEMU user-mode network 會把外部封包轉成 guest 看到的 Ethernet frame。

4. RX 接收流程

Driver 預先提供 buffer

RX descriptor 指向 virtio_net_hdr + frame，並設定 VIRTQ_DESC_F_WRITE。

→

Device 寫入封包

QEMU 收到外部 network packet 後，把資料寫進 RX buffer，再更新 used ring。

→

Driver poll used ring

讀出 frame，解析 destination MAC、source MAC、ethertype；處理後把 buffer 放回 RX queue。

RX queue 的關鍵是「先給 buffer」。如果 driver 沒有把 writable descriptors 放進 available ring，device 就算收到封包也沒有地方寫。

5. TX 傳送流程

Driver 組 Ethernet frame

buffer 前面放 virtio_net_hdr，後面接 Ethernet frame。第一版測試 frame 使用 broadcast MAC。

→

Descriptor 放入 TX queue

TX descriptor 不設定 VIRTQ_DESC_F_WRITE，因為 device 只需要讀取這段 buffer。

→

Device 送出後回報完成

device 更新 used ring；driver 看到 used.index 前進後即可重用 TX buffer。

6. 對應到目前程式碼

Makefile

加入 -netdev user,id=net0 與 virtio-net-device，掛到 virtio-mmio-bus.1。

virtio_net_init()

掃描 MMIO slot，找到 device id 1，建立 RX queue 0 和 TX queue 1。

virtio_net_enqueue_rx()

把 RX buffer descriptor 放入 available ring，並讓 device 可以寫入。

virtio_net_send_test_packet()

送出一個最小 Ethernet broadcast 測試 frame，確認 TX queue plumbing。

virtio_net_poll()

讀取 RX used ring，印出收到封包的長度與 ethertype，然後回收 RX buffer。

kernel_main()
  init_regions()
  virtio_blk_init()
  virtio_net_init()
    scan MMIO slots
    init RX queue 0
    init TX queue 1
    enqueue RX buffers
    set DRIVER_OK
  virtio_net_send_test_packet()
  virtio_net_poll()
  fs_init()
  init_processes()
